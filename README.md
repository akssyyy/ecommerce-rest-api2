# E-commerce REST API

Simple cloud-based REST API for products and orders.

## Features
- GET products
- POST products
- PUT products
- DELETE products
- Orders API
- Swagger documentation

## Technologies
- Node.js
- Express.js
- Swagger
- CodeSandbox

- ##API Link
- https://sh6sfd-3000.csb.app

- ##Swagger Docs
- https://sh6sfd-3000.csb.app/api-docs/#/
